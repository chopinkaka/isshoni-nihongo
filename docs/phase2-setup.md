# 2차 설치 안내 — 가족 진도 공유 (약 5분, 광우만 한 번)

구글 시트 하나와 Apps Script 하나만 있으면 됩니다. 아버지는 설치할 게 없고, 광우가 보내 주는 **가족 코드**만 앱에 붙여 넣으면 돼요.

> 구글 화면의 글자는 구글이 바꿀 수 있어서 아래 이름과 조금 다를 수 있어요. 막히면 화면을 캡처해서 알려 주세요.

## 1. 시트 만들기
1. 구글 계정(광우)으로 https://sheets.new 를 열어 새 시트를 만들고 이름을 「잇쇼니 진도」로 바꿉니다.
2. 위쪽 메뉴 **확장 프로그램 → Apps Script** 를 누릅니다. 새 탭에 코드 편집기가 열려요.

## 2. 코드 붙여넣기
1. 편집기에 있는 기본 코드(`function myFunction() {…}`)를 **전부 지웁니다**.
2. 저장소의 [`apps-script/Code.gs`](https://github.com/chopinkaka/isshoni-nihongo/blob/main/apps-script/Code.gs) 내용을 **전부 복사해서 붙여 넣습니다**.
3. 맨 위 한 줄을 고칩니다.
   ```js
   const FAMILY_KEY = 'CHANGE-ME';
   ```
   `CHANGE-ME` 자리에 **가족만 아는 12자 이상의 글자**(영문·숫자, 예: `ap7k2m9xq4wz`)를 넣어요. 이 키를 모르면 기록을 읽지도 쓰지도 못합니다. 키를 안 바꾸면 서버가 일부러 모든 요청을 거절해요.
4. 위쪽 💾(저장)을 누릅니다.

## 3. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**.
2. 톱니바퀴(유형 선택) → **웹 앱**.
3. 아래처럼 설정하고 **배포**를 누릅니다.
   - 실행 계정: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. 권한 승인 창이 뜨면 계정을 고르고 허용해요. 코드 맨 위의 `@OnlyCurrentDoc` 덕분에 권한 범위가 **「이 앱이 설치된 스프레드시트」 하나**로 제한돼서, 내 다른 시트는 건드리지 않아요. (「확인되지 않은 앱」 경고가 뜨면 **고급 → 이동 → 허용**)
5. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

## 4. 앱에 연결 → 아버지께 코드 보내기
1. 광우 폰 앱: **함께** 탭 → **처음 만드는 사람 (광우)** 를 펼칩니다.
2. 웹 앱 주소(3-5)와 가족 키(2-3)를 넣고 **코드 만들고 이 폰도 연결**을 누릅니다.
3. 「isshoni:…」로 시작하는 **가족 코드가 자동으로 복사**돼요. 카톡으로 아버지께 보냅니다. (이 코드가 곧 열쇠이니 가족방 밖으로는 공유하지 마세요.)
4. 아버지 폰 앱: **함께** 탭 → 「가족 코드를 받았어요」 칸에 붙여 넣고 **연결하기**.
5. 연결하면 지금까지의 학습 기록이 자동으로 올라가고, 이후엔 하루 학습을 끝낼 때마다 올라갑니다.

## 5. 잘 되는지 확인
- 시트에 **progress** 탭이 생기고 오늘 기록이 한 줄 들어옵니다. (같은 날 다시 끝내도 한 줄 그대로 — 중복 없음)
- **함께** 탭에서 두 사람의 연속 일수·누적 단어·이번 주 달력이 보이고, 응원(👏)이 **cheers** 탭에 쌓입니다.
- 인터넷이 안 될 때 끝낸 학습은 폰에 보관됐다가 연결되면 자동으로 올라가요.

## 나중에 알아 둘 것
- **코드를 고쳤을 때**: Apps Script에서 **배포 → 배포 관리 → ✏️(편집) → 버전: 새 버전 → 배포**. 주소는 그대로예요. (새 배포를 또 만들면 주소가 바뀝니다.)
- **키를 바꿀 때**: 2-3처럼 키를 바꾸고 위 방법으로 다시 배포한 뒤, 두 폰에 새 가족 코드를 다시 연결합니다.
- **연결 해제**: 함께 탭 맨 아래 「연결 해제」. 이 폰의 학습 기록은 그대로 남아요.
- 백업(내보내기) 파일에는 가족 키가 들어가지 않아요.
- 시트는 광우 구글 드라이브에 있어서 지우거나 공유 범위를 바꾸지 않는 한 그대로 유지됩니다.
